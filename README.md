## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Sobre el proyecto

WAVE Chat es una app de mensajeria mobile-first inspirada en interfaces como iMessage y Telegram. El proyecto prioriza una navegacion tactil, componentes visuales tipo app nativa y una interfaz enfocada en chats, llamadas, estados y ajustes dentro de un flujo consistente.
